# Understance

Understand before changing.

## The problem
You own software you did not fully build, and you are afraid to change it because you cannot see what a change will affect.

## What this does
It reads your Python repo, shows what a proposed change affects and why, with evidence behind every claim, and hands you a change brief for your own building tool. It reads and explains; it does not change your code.
